# triplehowl.com

The company site for Triplehowl LLC, the owner of the Housewright suite. Static HTML,
no build step, no external requests (fonts and images are local).

Preview: `python3 -m http.server 8931` and open http://127.0.0.1:8931/

Hosting: GitHub Pages from `main`, custom domain `www.triplehowl.com` (see `CNAME`).
DNS lives at Porkbun: apex A records 185.199.108.153 / .109 / .110 / .111.153,
`www` CNAME `shill21.github.io`. Leave the Google MX records alone.

Screenshots are copied from housewright.app and show sample data only.
