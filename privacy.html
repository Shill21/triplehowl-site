Nothing. triplehowl.com has no cookies, analytics, advertising, tracking or forms, and it loads nothing from other companies' servers.

The site is hosted on GitHub Pages. Like any web host, GitHub may keep standard server logs, such as IP addresses, to run and secure its service. Those logs are covered by GitHub's own privacy statement.
